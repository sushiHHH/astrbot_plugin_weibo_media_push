# AstrBot 微博媒体推送插件 (astrbot_plugin_weibo_media_push)

订阅微博博主，新微博自动推送原图文件和视频。支持 24 小时历史追更、可选文字合并转发、原图保真、去水印、多分辨率选择、网页管理界面。

## ✨ 功能

- 📦 **原图文件发送**：图片以 JPEG 文件发送，避免 QQ 图片消息压缩；指定窗口的文件进入文字合并转发节点
- 📝 **指定窗口合并转发**：可在配置中填写多个群号或完整 UMO，节点包含博主昵称、微博文字和原图文件
- 🎬 **视频推送**：视频独立发送，超过大小上限自动跳过
- 🔄 **24小时追更**：订阅时立即推送最近 24 小时内的媒体微博（可配置）
- 🚫 **去水印**：可配置裁剪图片底部微博水印区域；原图文件模式默认不裁剪
- 🎚️ **分辨率选择**：图片 4 档（原图/高清/中等/普通）、视频 4 档（1080P/720P/标清/360P）
- 🔢 **已推送统计**：每个博主累计推送条数
- 🌐 **网页管理**：AstrBot 面板内嵌"微博订阅管理"页面，可视化添加/删除/开关订阅
- 🔗 **多种地址格式**：支持数字 UID、`weibo.com/u/xxx`、个性域名 `weibo.com/name`
- 🧹 **不留残留**：图片和视频发送后立即删除，服务器不保留媒体文件

## 📦 安装

1. 将本插件目录放入 AstrBot 插件目录：
   ```
   data/plugins/astrbot_plugin_weibo_media_push/
   ```
2. 重启 AstrBot（或面板里启用插件）
3. **配置微博 Cookie**（必须）：
   - 电脑浏览器登录 [weibo.com](https://weibo.com)
   - F12 → Network → 刷新页面 → 任选请求 → 复制 Request Headers 里的 `Cookie`
   - 在插件配置页填入，或对机器人发送 `/微博设置cookie <Cookie>`

## 🎯 使用

### QQ 命令

| 命令 | 说明 |
|---|---|
| `/微博订阅 <UID或主页链接或个性域名>` | 订阅博主并追更最近 24 小时 |
| `/微博退订 <UID>` | 退订 |
| `/微博列表` | 查看订阅（含推送统计） |
| `/微博推送 开启\|关闭` | 开关当前会话推送 |
| `/微博测试 <UID>` | 立即推送最新一条含媒体的微博 |
| `/微博设置cookie <Cookie>` | 更新 Cookie（管理员） |
| `/微博清空订阅` | 清空所有（管理员） |

### 网页管理界面

AstrBot 面板 → 插件 → 微博媒体推送 → **微博订阅管理** 页面：
- 自动列出机器人所在的所有 QQ 群
- 选中群 → 输入 UID/链接 → 一键添加
- 每个博主显示"已推送 N 条"徽章，可独立开关/移除
- 群级"全部推送"总开关、轮询间隔设置

## ⚙️ 配置项

| 配置项 | 默认 | 说明 |
|---|---|---|
| 微博登录 Cookie | 空 | 必填，weibo.com 登录后复制 |
| 轮询间隔（分钟） | 5 | 检查新微博的频率 |
| 订阅时追更最近N小时 | 24 | 订阅时立即推送最近 N 小时媒体（0=关闭） |
| 去除图片水印 | 开 | 裁剪图片底部水印区域 |
| 水印裁剪比例 | 0.10 | 裁剪底部比例（0-0.5） |
| 图片分辨率 | 高清 | 原图/高清(mw2000)/中等(mw1024)/普通(mw690) |
| 视频清晰度 | 720P | 1080P/720P/标清/360P，自动降级 |
| 推送转发微博 | 关 | 是否推送博主转发的微博 |
| 视频大小上限（MB） | 200 | 超限视频跳过 |
| 文字合并转发窗口 | `634179473` | 多个群号/完整 UMO 用逗号、空格或换行分隔；留空则所有窗口均发送原图文件但不带微博文字 |

## 📨 消息与原图说明

- 所有窗口的图片均以原始 JPEG 文件发送，避免 QQ 图片消息自动压缩。
- 配置在“文字合并转发窗口”中的群，会将博主昵称、微博文字和原图文件放入合并转发节点。
- 未配置的窗口仍发送原图文件和视频，但不附带微博文字。
- 视频需要临时下载后发送，发送成功或失败都会立即删除；图片临时文件同样不会长期保留。
- 文件消息可能不会直接显示图片预览，需要点击文件查看原图。

## ⚠️ 注意事项

- **需要微博 Cookie**：微博对数据中心 IP 的无 Cookie 访问有限制（HTTP 432），必须配置登录 Cookie
- **去重**：已推送的微博会被记录，重新订阅不会重复发送
- **Cookie 安全**：Cookie 含登录态，仅在插件配置中保存；如泄露可在微博设置中"退出所有设备"作废
- **媒体隐私**：图片和视频只在发送期间临时写入服务器，发送完成后立即删除；QQ/群文件本身可能由平台按其规则保存
